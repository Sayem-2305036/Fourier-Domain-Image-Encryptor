## Overview

This project explores optical signal processing and cryptographic image security. It implements a side-by-side comparison of the classic Double Random Phase Encoding (DRPE) algorithm and a custom-built, highly secure Advanced Chaotic DRPE Pipeline.

The application demonstrates how standard linear encryption fails under targeted attacks and how introducing non-linear chaos math, fractional wave rotations, and dynamic hashing completely neutralizes those vulnerabilities.

## The Problem: Securing Visual Data

Images contain massive amounts of highly correlated data. If you encrypt a picture of a face using basic mathematical scrambling, the underlying shape of the face often leaks through the ciphertext. Securing an image requires completely destroying both the pixel colors and the physical structure (edges and shapes) while ensuring the receiver can mathematically reverse the damage without data loss.

## The Baseline Solution: Standard DRPE

Standard DRPE solves the structural leakage problem by encrypting the image in the frequency domain.
Instead of scrambling physical pixels, it uses a Fast Fourier Transform (FFT) to convert the picture into a map of intersecting light waves. It applies two massive 2D grids of random numbers (Phase Masks) to scramble the energy of those waves. When converted back to physical pixels, the image becomes pure, unrecognizable television static.

### Why Standard DRPE Fails

Standard DRPE relies on linear mathematics, which creates two severe cryptographic vulnerabilities:

* **No Avalanche Effect:** If an attacker guesses a password that is 99% correct, a linear equation will reconstruct 99% of the image. The wrong 1% simply looks like a light layer of background static, leaving the target image completely visible.
* **Static Keys:** The random phase masks do not change based on the input image. If an attacker feeds a blank image into the system (a Chosen-Plaintext Attack), they can map out exactly how the system scrambles data and easily reverse-engineer the keys.

## The Advanced Solution: Chaotic DRPE Pipeline

To build a mathematically impenetrable system, the Advanced mode abandons linear random masks and static keys. It dynamically generates its entire mathematical structure from the image itself, splits the signal using wavelets, and scrambles the data using fractional wave rotations driven by highly unstable chaos equations.

### Signal Processing Concepts Integrated

This advanced pipeline leverages two distinct signal processing transformations to boost security:

#### 1. Discrete Wavelet Transform (DWT)

Before encryption, the image is passed through a Haar Wavelet filter. Think of this as a digital strainer that separates the image into four distinct layers: one blurry base layer containing the core colors, and three edge layers containing the sharp horizontal, vertical, and diagonal details. All four bands are then individually encrypted to ensure a lossless round-trip for authorized users and total structural collapse for attackers.

#### 2. Fractional Fourier Transform (FrFT)

A standard FFT rotates a signal exactly 90 degrees from physical pixels into waves. The FrFT allows the signal to be rotated to any continuous decimal angle (e.g., 42.6 degrees). We use an advanced eigen-decomposition engine to compute exact, reversible fractional wave states, treating the rotation angles on the X and Y axes as an entirely new set of secret keys.

### Cryptographic Security Mechanisms

* **Dynamic Key Derivation (SHA-256):** The system extracts a unique 64-character SHA-256 fingerprint from the physical bytes of the uploaded image. This hash is mathematically sliced to dynamically dictate the starting passwords for the chaos engines and the exact decimal angles for the FrFT. Every new image creates an entirely unique mathematical lock, defeating Chosen-Plaintext Attacks.
* **The Chaotic Logistic Map (The Avalanche Effect):** Instead of random numbers, the phase masks are generated by the Logistic Map equation. This equation acts like a highly unstable pinball machine. If an attacker inputs a decryption password that is off by just 0.00001, the mathematical cascade wildly diverges. This microscopic error completely breaks the frequency wave reconstruction, resulting in a 100% loss of visual structure (global diffusion) rather than just a localized blur.

## Interactive Simulation Sliders (Stress-Testing the System)

To demonstrate how these algorithms perform in the real world, the application includes interactive sliders. These allow you to simulate physical transmission problems and hacking attempts.

### 1. Key Error % (The Hacker Simulator)

* **What it is:** This slider lets you inject a tiny, microscopic mistake into the decryption password just before unlocking the image.
* **What it imitates:** It mimics a situation where an attacker is guessing a password and gets it almost right (e.g., 99.9% correct). In Standard DRPE, a small error just makes the image slightly blurry. In our Advanced Chaotic DRPE, a 0.001% error completely breaks the decryption, resulting in pure white noise.

### 2. Crop Area % (The Data Loss Simulator)

* **What it is:** This slider digitally cuts out and removes a percentage of the encrypted image.
* **What it imitates:** It simulates severe data loss. Imagine you are downloading an encrypted file, and your internet cuts out halfway through, leaving you with an incomplete file. It tests if the original image can still be salvaged from the remaining fragments.

### 3. Noise Power % (The Interference Simulator)

* **What it is:** This adds random digital static over the top of the encrypted image.
* **What it imitates:** It simulates a "noisy" communication channel. This is like trying to talk on a walkie-talkie while there is a lot of static and interference in the background. It tests the system's ability to filter out injected junk.

### 4. Bandwidth % (The Low-Pass Filter / Bad Signal Simulator)

* **What it is:** Applied to both pipelines, this slider acts like a narrow pipe for data. It allows slow, broad waves to pass through but permanently deletes the fast, sharp wave details (which contain the crisp edges of the original image).
* **What it imitates:** It simulates sending secure data over a terrible network connection where pieces of the file are permanently degraded, like a weak Wi-Fi signal or dropping packets over a satellite link. By sliding this down, you can see how much data can be destroyed before the receiver is completely unable to recognize the decrypted image.

## Installation & Usage

### Prerequisites

Ensure you have Python 3.x installed along with the required scientific and UI libraries:

```bash
pip install numpy matplotlib pillow PyWavelets

```

### Running the Application

1. Clone this repository and navigate to the folder.
2. Execute the main application file:
```bash
python app.py

```



### Testing the System

* **Standard vs. Advanced:** Toggle between the two algorithms using the radio buttons at the top left.
* **Encrypting:** Load an image and click *Encrypt Image*. In Advanced mode, the keys (derived via SHA-256) are generated automatically.
* **Export / Import:** Export the CipherText and Keys to your local drive. You can completely close the application, reopen it, and import those files to mimic a real-world secure transmission. The application will automatically detect the key format and switch to the correct decryption mode.
* **Proving the Avalanche Effect:** In Advanced mode, slide the Key Error % to `0.1` and click decrypt. The microscopic error will cascade through the chaotic map, failing to reconstruct the FrFT frequency bands and resulting in pure, structureless white noise.
